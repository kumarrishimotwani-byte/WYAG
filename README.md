# WYAG
project_summer
wyag — Write Yourself a Git

A Python implementation of Git built from scratch, fully compatible 
with real git. Implements the core object storage system (blobs, trees, 
commits, tags), commit history traversal, branch/tag management, 
staging area, and more.

Commands: init, hash-object, cat-file, log, ls-tree, checkout, 
          show-ref, tag, rev-parse, ls-files, check-ignore, 
          status, rm, add, commit

Built following the WYAG tutorial (wyag.thb.lt) with deep focus 
on understanding every line of code rather than copying.
